PROJECT 01

Rail Pass Management System

● Designed and developed a Rail Pass Management System using PHP and MySQL to streamline daily commuter pass issuance and eliminate manual paperwork.

● Built a responsive, user-friendly frontend with HTML, CSS, Bootstrap, and jQuery, enabling commuters to search for their profiles and print passes directly via unique pass numbers.

● Created a centralized administrative panel to manage category configurations, track daily/weekly pass generation metrics, handle public inquiries, and generate periodic transit reports.

● Enhanced application security by implementing MD5 encryption for admin authentication and credential management.

● Tested, optimized, and deployed the complete application on an Apache/MySQL local server environment via XAMPP, successfully conducting end-to-end user acceptance testing and verifying database integrity for daily operations.

HTML | CSS | MySQL | PHP | Bootstrap | jQuery

PROJECT 02

Deepfake Detection: Distinguishing Real vs. AI-Generated Faces via Adversarial Features

● Designed and developed an end-to-end Deepfake Detection System using Python and PyTorch to classify authentic human faces versus AI-generated (GAN) facial media.

● Built an automated preprocessing pipeline using OpenCV and MTCNN for face extraction, alignment, 224 × 224 normalization, and high-frequency noise residual analysis.

● Trained and fine-tuned an EfficientNet-B0 deep learning architecture using Binary Cross-Entropy (BCE) loss and the AdamW optimizer on LFW and GAN-generated datasets.

● Implemented Fast Gradient Sign Method (FGSM) adversarial training and compression augmentations to improve model robustness against unseen manipulations and low-resolution media.

● Integrated the trained model (deepfake_model.pth) into a Flask RESTful web API with an interactive UI, successfully conducting unit, integration, and stress testing to deliver real-time authenticity probability scores.

Python | PyTorch | OpenCV | MTCNN | Flask | HTML | CSS
GitHub Code ↗
PROJECT 03

E-Commerce Sales & Business Analytics Using Power BI

● Cleaned and standardized multi-table e-commerce datasets (customers, products, orders, order_items, and employees covering 500+ orders and 1,187 line items) in MS Excel to resolve formatting inconsistencies and prepare data for analysis.

● Modeled relational schemas and executed SQL queries in MySQL by linking primary and foreign keys (customer_id, order_id, product_id, employee_id) to analyze INR 1.30 Cr+ in transaction revenue across 6 product categories.

● Engineered custom DAX measures in Power BI to track critical KPIs including Total Sales, Total Profit, Profit Margin %, Average Order Value (AOV), Repeat Customer Rate %, Delivery Rate %, Return Rate %, and Operational Risk Rate %.

● Developed a 5-page interactive Power BI dashboard (Executive Overview, Sales & Profit Analysis, Customer Insights, Product Performance, and Operations & Delivery) featuring dynamic slicers for State, Category, and Month.

● Delivered actionable business insights at the end of the project by identifying high-margin product categories, evaluating payment method trends, and pinpointing regional order cancellation and return bottlenecks to optimize fulfillment operations.

SQL | Power BI | Analytics | Visualization | MySQL
GitHub Code ↗
